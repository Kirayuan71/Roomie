# Roomie · 室友搭子

让合租生活有账可查、有事可商、有约可依。

Roomie 面向年轻合租群体，把费用分摊、清洁值日、公共用品、生活约定和日常沟通集中管理，减少反复对账、催家务和忘记补货的琐碎，让室友之间的分工更清楚、沟通更轻松。

**在线体验：[roomie-kira.streamlit.app](https://roomie-kira.streamlit.app/)**

## 功能模块

| 模块 | 可以做什么 |
| --- | --- |
| 生活概览 | 查看待收款、待完成清洁和低库存提醒；通过小家日历管理值日、室友生日、卫生检查及其他安排。生日支持每年重复。 |
| 互动留言板 | 发布生活消息，回复室友、点赞互动，编辑或删除自己的留言。 |
| 费用账本 | 记录支出和付款人，选择分摊参与者，按平均或自定义比例计算费用；按月查看账单，进行单笔或室友间净额结算，支持撤销结算。 |
| 清洁值日 | 创建任务、指定负责人和截止时间，查看周排班、完成打卡或换班；支持自动轮换，周期任务完成后安排下一次值日。 |
| 公共物品 | 管理库存与补货阈值，将物品加入采购清单、认领采购；补货完成后更新库存，并可自动生成 AA 账单。 |
| 室友公约 | 使用模板或自行起草约定，按类别管理规则；全员同意后生效，修改后重新投票，并保留修改记录。 |
| AI 生活助手 | 在演示模式下，将含金额与付款人的文字解析为记账草稿，或提供公约和友好提醒模板；确认后才写入数据。 |

## 如何使用

### 1. 进入演示小家

打开在线站点即可使用，无需登录。应用预置三名室友及账单、值日、物品和公约等演示数据。

在「小家设置」中切换当前室友身份，可以体验不同室友的投票、留言与采购认领。该身份切换仅用于演示。

### 2. 记录一笔共同支出

进入「费用账本」，点击「新增支出」，填写名称、金额、付款人、日期和类别，再选择分摊参与者。默认平均分摊，也可调整各人的比例。

保存后即可查看每人分摊金额及待结算状态。实际转账完成后，标记单笔结算，或按净额结算建议统一确认；误操作时可撤销。

### 3. 安排和完成家务

进入「清洁值日」创建任务，或为选定周生成自动轮换排班。任务支持修改负责人、截止时间和周期，完成后点击打卡。

清洁安排会同步出现在首页日历中。生日、卫生检查和其他生活提醒可直接在日历中添加、修改或删除。

### 4. 补充公共用品

在「公共物品」记录物品库存及低库存阈值，消耗时减少库存。需要补货时加入采购清单，由室友认领。

完成采购时填写数量和金额；勾选生成 AA 账单，即可同时更新库存与费用账本。

### 5. 一起商量生活约定

在「室友公约」选择模板或新增规则，提交后进入投票。可通过设置切换演示身份，体验三位室友全部同意后公约生效的流程。

日常消息可以发到首页留言板，用回复和点赞交流。

### 6. 体验助手或重新开始

在「AI 生活助手」输入如「林小满买洗衣液花了32元」，查看并核对解析草稿，确认后保存到账本。也可选择公约或友好提醒模板。

想从初始状态重新体验，可在「小家设置」中点击「重置演示数据」。此操作会清除当前浏览器中的修改。

## 当前版本说明

- **数据保存在当前浏览器。** 刷新页面后保留修改；不同设备、浏览器及室友之间暂不共享数据。清除浏览器站点数据会删除本地记录。
- **助手为演示模式。** 使用有限的本地规则解析和固定模板，尚未接入真实 AI 服务，不会未经确认修改账单或公约。
- **无需登录。** 当前身份切换不代表真实认证或权限控制，适合体验产品流程。

## 本地运行

使用 Node.js 20.19+ 与 npm，在仓库目录执行：

```bash
npm ci
npm run dev
```

测试及生产构建：

```bash
npm test
npm run build
npm run preview
```

如需通过 Streamlit 运行，先完成前端构建，再执行：

```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py --global.developmentMode false --server.headless true
```

Streamlit Community Cloud 的入口为 `streamlit_app.py`。前端更新后，请将重新构建的 `dist/` 一并提交，并持续更新同一个应用，以保留现有站点地址。
